前置概念：四种核心运算

内积 (Inner Product)

又叫点积 (Dot Product)。两个向量对应位置相乘再求和，最终得到一个标量（一个数字）。

⟨a, b⟩ = Σᵢ aᵢ · bᵢ = a₁b₁ + a₂b₂ + ... + aₖbₖ

直觉：衡量两个向量的相似度。方向越一致，内积越大；正交时内积为零。

输入输出：

输入: 两个 k 维向量 输出: 1 个标量 信息量: 最压缩

代表模型：

- FM: ⟨vᵢ, vⱼ⟩ 作为两个特征的交互权重

- DLRM: embedding 间的点积交互矩阵

内积是最简单也最高效的交互方式。把两个 k 维向量压缩成一个数，信息损失最大，但计算最快。FM 能工作的前提就是：内积已经足够编码两个特征间的交互强度。

Hadamard 积 / 逐元素乘 (CTR 领域常说的"外积")

两个向量对应位置相乘，不求和，保留每一维的结果，输出仍然是一个k 维向量。

a ∘ b = [a₁b₁, a₂b₂, ..., aₖbₖ]

直觉：保留了两个向量交互后的完整信息，没有像内积那样压缩成标量。每一维的交互结果都保留下来。

与内积的关系：

内积 = sum(Hadamard 积)
⟨a,b⟩ = Σ(a ∘ b) = sum([4,10,18]) = 32

所以 Hadamard 积包含的信息严格多于内积——你随时可以从 Hadamard 积求和得到内积，但反过来不行。

代表模型： xDeepFM 的 CIN — 在 vector 级别做 Hadamard 积，保留 field 的向量结构。

CTR 领域的术语混淆：论文中常把 Hadamard 积称为"外积"（outer product），但严格来说数学中的外积是另一种运算（见下方）。读论文时要根据上下文判断，如果输出是向量，就是 Hadamard 积。

张量外积 (Outer Product)

数学意义上的真正外积：两个向量的每一对元素都做乘法，输出一个k×k 矩阵。

(a ⊗ b)ᵢⱼ = aᵢ · bⱼ
3维向量 → 3×3 = 9 个元素

直觉：捕获了两个向量之间所有可能的维度对组合。信息量最大，但参数量也最大。

三种运算的信息量排序：

张量外积: k²个值 (最丰富) Hadamard 积: k个值 (中等) 内积: 1个值 (最压缩)

代表模型： PNN (Product-based Neural Network) 使用外积矩阵。但由于 k² 的参数量，在工业中较少使用。

实际应用较少的原因：外积产出 k×k 矩阵，参数量和计算量呈平方增长。大多数模型选择内积（FM, DLRM）或 Hadamard 积（CIN）作为折中。

交叉 (Cross) — DCN 专属

交叉操作是 DCN 提出的独特运算，既不是内积也不是外积，而是一种用内积结果缩放原始输入的操作。

xₗ₊₁ = x₀ · (xₗᵀ · w) + b + xₗ

拆解为三步：

1. xₗᵀ · w → 当前层与参数做内积，得到一个标量

2. x₀ · 标量 → 用标量缩放原始输入 x₀

3. + xₗ → 加上当前层（残差连接）

关键特性：

输入输出维度相同 (d维→d维) 每层只需 O(d) 参数 每多一层，交互阶数 +1

代表模型： DCN, DCN-V2, MMCN

交叉的精妙之处：用极少的参数（每层只要 d 个）实现了显式的高阶特征交互。L 层 Cross Network = (L+1) 阶交互，参数量只有 O(d·L)，远少于 DNN 的 O(d²·L)。

四种运算一览对比

运算 公式 输入 输出 信息量 代表模型 计算量
内积 Σ aᵢbᵢ 两个 k 维向量 1 个标量 最压缩 FM, DLRM, DIN O(k)
Hadamard 积 [aᵢbᵢ, ...] 两个 k 维向量 k 维向量 中等 xDeepFM (CIN) O(k)
张量外积 aᵢbⱼ (矩阵) 两个 k 维向量 k×k 矩阵 最丰富 PNN O(k²)
交叉 (Cross) x₀·(xₗᵀw)+xₗ d 维 + d 维 + d 参数 d 维向量 显式高阶 DCN, MMCN O(d)

选择逻辑： 信息量越大，计算越贵。工业界的选择通常是：内积（大规模、低延迟）或交叉（显式高阶、参数高效）。 Hadamard 积是信息与效率的折中。张量外积理论最强但实践中较少使用。

1
LR — Logistic Regression

LR: CTR 预估的起点

Logistic Regression 是 CTR 预估最基础的模型，将每个特征独立地映射到点击概率。

P(y=1|x) = sigma(w₀ + Sigma_i w_i x_i)

核心特点:

- 输入为 one-hot 编码的高维稀疏向量 (百万~千万维)

- 每个特征拥有一个独立权重 w_i

- 特征之间完全独立，无任何交互建模

根本局限: 无法捕捉特征间的组合效应。例如「性别=女」与「广告类目=美妆」各自独立贡献，但它们的组合效应远大于线性叠加。

线性模型 无特征交互 高维稀疏 可解释性强 工业基线
LR 的历史地位: 尽管简单，LR 凭借高效、稳定和可解释性，在工业界长期作为 CTR 预估的标准基线。它的局限催生了所有后续模型的发展。
2
POLY2 — Polynomial (Degree 2)

POLY2: 暴力枚举所有二阶交叉

POLY2 是对 LR 最直接的改进: 显式枚举所有特征对 (x_i, x_j) 并为每对学习一个独立权重 w_ij。

y = w₀ + Sigma_i w_i x_i + Sigma_{i=1}^{n} Sigma_{j=i+1}^{n} w_{ij} x_i x_j

解决的问题: 相比 LR，首次引入了特征交互建模。

根本缺陷:

- 参数爆炸: 需要 O(n^2) 个交互权重。当 n=100万特征时，参数量达到万亿级别

- 数据稀疏: 绝大多数特征对 (x_i, x_j) 在训练集中从未共现过，w_ij 无法有效学习

- 无泛化能力: 每个 w_ij 独立学习，从未共现的特征对无法获得有意义的交互权重

显式二阶交互 O(n^2) 参数 无泛化能力 稀疏数据问题
POLY2 的教训: 直接学习 n x n 的交互矩阵在高维稀疏场景不可行。这正是 FM 通过矩阵分解解决的核心问题。
3
FM — Factorization Machines (2010, Rendle)

FM: 矩阵分解拯救特征交互 (Rendle, 2010)

核心洞察: 不直接学习 n x n 的交互权重矩阵 W，而是将其分解为低秩近似。

y = w₀ + Sigma_i w_i x_i + Sigma_{i<j} <v_i, v_j> x_i x_j

其中 w_ij ~ <v_i, v_j> = Sigma_{f=1}^{k} v_{if} * v_{jf}

关键创新:

- 每个特征用一个 k 维隐向量 v_i 表示 (k << n)

- 参数量从 O(n^2) 降到 O(kn)

- 即使特征 i 和 j 从未共现，只要它们各自与其他特征有过交互，就能通过隐向量泛化出有意义的 w_ij

O(kn) 计算技巧: 通过数学恒等变换，二阶交互项可以在 O(kn) 而非 O(kn^2) 时间内计算。

矩阵分解 隐向量 O(kn) 复杂度 二阶交互 泛化能力
FM 的里程碑意义: 首次在稀疏数据上高效且泛化地建模特征交互。它奠定了所有后续 CTR 模型的 Embedding 思想基础。局限是只能建模二阶交互。
4
FFM — Field-aware FM (2016, Juan et al.)

FFM: 感知 Field 的精细化交互 (Juan et al., 2016)

核心洞察: 在 FM 中，每个特征只有一个隐向量 v_i，无论与哪个域的特征交互都用同一个。但直觉上，「用户年龄」与「广告类目」交互时应使用不同的表示，与「时间」交互时又该不同。

y = w₀ + Sum w_i x_i + Sum_{i<j} <v_{i,f_j}, v_{j,f_i}> x_i x_j

v_{i,f_j}: 特征 i 面向域 f_j 的专用隐向量

关键改进: 每个特征为每个 field 维护一个独立的隐向量。如果有 f 个 field，则每个特征有 f 个 k 维向量。

代价: 参数量从 FM 的 O(kn) 增长到 O(kfn)。

Field-aware O(kfn) 参数 Criteo/Avazu 竞赛冠军 更精细的交互
FFM 的贡献: 在多个 CTR 竞赛中取得冠军，证明了 field-aware 交互的重要性。但参数量和复杂度的增长限制了其在超大规模工业场景的应用。
5
Wide & Deep (2016, Google)

Wide & Deep: 记忆与泛化的结合 (Google, 2016)

核心思想: 模型需要两种能力 -- Memorization (记住高频共现) 和 Generalization (泛化到未见模式)。

P(y=1) = sigma(w_wide^T [x, phi(x)] + w_deep^T a^(l_f))

Wide 组件: 线性模型 + 手工交叉特征 phi(x)，擅长记忆（如「用户A AND 物品B -> 点击」）

Deep 组件: Embedding + 多层 DNN，擅长泛化（发现未见过的特征组合）

关键局限:

- Wide 侧的交叉特征 phi(x) 需要人工设计，依赖领域知识

- Wide 和 Deep 的输入表示不同，缺少共享

Google Play 推荐 Memorization + Generalization 需要手工特征工程 联合训练
Wide & Deep 的里程碑意义: 首次在工业界大规模验证了「浅层记忆 + 深层泛化」的双路架构范式，深刻影响了后续所有 CTR 模型的设计思路。其局限 (手工特征工程) 直接催生了 DeepFM。
6
DeepFM — FM + DNN Shared Embedding (2017, Huawei)

DeepFM: 自动特征交叉 + 共享 Embedding (Huawei, 2017)

DeepFM 对 Wide & Deep 的三大改进:

y = sigma(y_FM + y_DNN)
y_FM = w0 + Sum w_i x_i + Sum <e_i, e_j>
y_DNN = DNN(concat(e1, e2, ..., em))

1. 共享 Embedding: FM 和 DNN 使用同一组 Embedding 向量，双路梯度共同优化

2. FM 替代 Wide: 用 FM 自动学习二阶交互，无需手工特征工程

3. 端到端训练: 一个优化器统一训练，不再需要分别优化

仍存在的局限: DNN 的高阶交互是隐式的 (bit-wise 黑盒)，无法控制交互阶数。

共享 Embedding 无需特征工程 FM + DNN 端到端训练 工业标准 Baseline
DeepFM 是工业 CTR 预估的标准起点。 共享 Embedding 是核心创新 -- FM 侧的梯度和 DNN 侧的梯度共同优化同一组 Embedding，低阶与高阶交互信号互相增强。
7
DCN — Deep & Cross Network (2017, Google)

DCN: 显式交叉层建模高阶交互 (Google, 2017)

核心创新: Cross Network -- 用显式的交叉层 (Cross Layer) 逐层提升交互阶数，每层仅需 O(d) 参数。

Cross Layer:
x_{l+1} = x₀ * (x_l^T * w_l) + b_l + x_l

- x₀: 原始输入
- w_l, b_l: 第 l 层参数 (仅 d 维向量!)
- L 层 Cross Network -> L+1 阶交互

关键优势:

- 显式建模有界阶交互 (L+1 阶)

- 每层参数量仅 O(d)，L 层总参数 O(d * L)，极度参数高效

- 与 DNN 并联，显式 + 隐式互补

局限: 每层的交叉是 x₀ * (x_l^T * w)，中间 x_l^T * w 是标量，表达能力有限 (rank-1 constraint)。

Cross Layer O(d*L) 参数 显式有界阶 参数高效 Rank-1 局限
DCN 开创了 Cross Network 范式。 用极少的参数实现显式高阶交互，但 rank-1 的限制使得每层的交叉表达能力受限，这正是 DCN-V2 要解决的问题。
8
xDeepFM — CIN + DNN (2018, Microsoft KDD)

xDeepFM: CIN 实现 Vector-wise 显式高阶交互 (Microsoft, KDD 2018)

x = eXtreme。 xDeepFM 同时实现显式 (CIN) + 隐式 (DNN) 的任意阶特征交互。

y = sigma(y_Linear + y_CIN + y_DNN)

CIN 核心操作:
X^{k+1}_h = Sum_i Sum_j W^k_{h,i,j} (X^k_i . X^0_j)
. = Hadamard product (逐元素乘)

CIN 的核心创新:

- Vector-wise 交互: 保留 field embedding 的向量结构 (区别于 DNN 的 bit-wise)

- 阶数可控: T 层 CIN = T+1 阶交互

- 每层与 X^0 交互: 保证阶数精确递增

- 压缩: 用 W 矩阵压缩中间张量，避免指数膨胀

局限: CIN 的计算复杂度 O(mHkT) 较高，工业部署时需要权衡。

CIN Vector-wise 显式高阶 阶数可控 Hadamard 积
xDeepFM 的理论贡献: 首次在 CTR 领域实现了 vector-wise 的显式有界阶高阶交互。CIN 与 DNN 形成显式+隐式的终极互补。但计算开销限制了其工业规模应用。
9
DCN-V2 — Deep & Cross Network V2 (2020, Google)

DCN-V2: 矩阵交叉 + 专家混合 (Google, 2020)

核心改进: 将 DCN 交叉层的向量 w 替换为矩阵 W，打破 rank-1 限制。

DCN v1: x_{l+1} = x₀ * (x_l^T w_l) + b_l + x_l
↑ 标量 (rank-1)

DCN-V2: x_{l+1} = x₀ . (W_l x_l + b_l) + x_l
↑ d维向量 (full-rank)
. = Hadamard product (逐元素乘)

关键改进:

- 矩阵替代向量: W_l 是 d x d 矩阵，表达能力大幅提升

- MoE 变体: 多个专家的交叉层通过 Gating 加权组合，进一步提升容量

- Stacked / Parallel: 支持串联和并联两种组合模式

参数开销: d x d 矩阵参数量较大，可通过低秩分解 W = U * V^T 缓解。

矩阵交叉 Full-rank MoE 变体 低秩分解 Stacked/Parallel
DCN-V2 是 Cross Network 的成熟形态。 矩阵交叉解决了 DCN v1 的 rank-1 瓶颈，MoE 变体进一步增强了模型容量。在 Google 内部大规模生产系统中验证有效。
10
AutoInt — Automatic Feature Interaction (2019)

AutoInt: 自注意力驱动的特征交互 (2019)

核心思想: 用 Transformer 的多头自注意力机制 (Multi-Head Self-Attention) 来自动学习特征之间的交互关系。

Attention(Q, K, V):
alpha_{m,k} = softmax(Q_m^T K_k / sqrt(d'))
e_m' = Sum_k alpha_{m,k} V_k

Q = e W_Q, K = e W_K, V = e W_V

关键创新:

- 每个 field 的 embedding 通过注意力机制聚合其他所有 field 的信息

- 注意力权重 alpha 自动学习哪些特征对交互更重要

- 多层叠加可以捕捉高阶交互

- 残差连接保留原始信息

可解释性: 注意力权重提供了特征交互的可视化解释。

Multi-Head Attention 自动特征交互 可解释性 Residual Transformer 式
AutoInt 的独特价值: 将 Transformer 的自注意力引入 CTR 预估，开启了注意力机制在特征交互中的应用。注意力权重提供了比 DNN 更好的可解释性。
11
FiBiNET — Feature Importance and Bilinear (2019)

FiBiNET: SENET + 双线性交互 (2019)

FiBiNET 从两个维度增强特征交互:

1. SENET: 自适应 field 重要性
s = Squeeze(E), a = Excitation(s)
E' = a . E (按 field 加权)

2. Bilinear: p_ij = e_i^T W e_j
W 是可学习矩阵，比内积更灵活

SENET Layer (Squeeze-and-Excitation):

- 借鉴 CV 中的 SENet 思想

- Squeeze: 对每个 field embedding 做 pooling 压缩为标量

- Excitation: FC + sigmoid 生成 field 级别的重要性权重

- 自适应地放大重要 field、抑制噪声 field

Bilinear Interaction:

- 用可学习矩阵 W 代替简单内积: p_ij = e_i^T W e_j

- 三种变体: field-all (共享 W), field-each (每对 field 独立 W), field-interaction (每种交互类型一个 W)

SENET Bilinear Interaction Field Importance 自适应加权
FiBiNET 的创新: 同时解决了「哪些 field 重要」(SENET) 和「field 之间如何交互」(Bilinear) 两个问题。SENET 的 field 重要性动态调整是其独特贡献。
12
DLRM — Deep Learning Recommendation Model (2019, Meta)

DLRM: Meta 的工业级推荐模型 (2019)

设计哲学: 面向工业规模部署，架构简洁高效，强调 Embedding 表的并行化。

Architecture:
1. Dense features -> Bottom MLP -> d-dim vector
2. Sparse features -> Embedding Lookup -> d-dim vectors
3. All d-dim vectors -> Pairwise Dot Product
4. concat(dot products, dense_out) -> Top MLP -> y

关键设计:

- Bottom MLP: 将连续特征映射到与 embedding 相同的维度空间

- Dot Product 交互: 所有 embedding (包括 Bottom MLP 输出) 之间的两两内积

- Top MLP: 将交互结果映射到预测值

- 工业优化: Embedding 表分布在多 GPU/多机上，通信模式高度优化

Meta 工业级 Embedding 并行 Bottom/Top MLP Dot Product 交互 分布式训练
DLRM 的工业意义: 不追求最复杂的交互机制，而是在简洁的架构下实现极致的工程效率。其 Embedding 分布式并行方案成为大规模推荐系统的工程标准。
13
MMCN — Multi-Head Multi-Layer Cross Network

MMCN: 多头交叉 = 多子空间显式交互

核心思想: 借鉴 Transformer 的多头注意力思想，在 Cross Layer 中引入多个独立的交叉头 (heads)。

Multi-Head Cross Layer:
head_h = x₀ . (W_h x_l + b_h) + x_l
x_{l+1} = concat(head_1, ..., head_H) W_proj

每个头在不同的子空间中学习交叉模式

解决的问题: DCN-V2 中每层只有一个 W 矩阵，所有交互在同一个子空间。MMCN 将交互分散到多个子空间，每个头捕捉不同类型的交叉模式。

关键优势:

- 更丰富的交叉表达 (多子空间)

- 类似多头注意力的分而治之策略

- 每个头可以用较小的 W，总参数量可控

Multi-Head 多子空间交叉 DCN-V2 扩展 投影层聚合
MMCN = Multi-Head DCN-V2。 多头机制让模型在不同子空间中独立学习特征交叉模式，然后通过投影层聚合。这是 Cross Network 向更强表达能力演进的自然方向。
14
DHEN — Deep Hierarchical Ensemble Network (2022, Meta)

DHEN: 异构算子的层次化集成 (Meta, 2022)

核心思想: 不再固定用一种交互机制 (如只用 CrossNet 或只用 Attention)，而是在每一层中组合多种异构交互算子。

Layer l: x_{l+1} = concat(
CrossNet(x_l),
SelfAttention(x_l),
MLP(x_l),
Linear(x_l),
... // 可插拔
) * W_proj

关键创新:

- 异构 (Heterogeneous): 每层可以包含 CrossNet + Attention + MLP + Linear 等不同类型的算子

- 层次化 (Hierarchical): 多层叠加，上层的输入是下层所有算子的联合输出

- 可插拔 (Pluggable): 可以灵活配置每层使用哪些算子、多少个

工业验证: 在 Meta 的广告推荐系统中取得显著收益。

Meta 2022 异构算子 层次化集成 可插拔模块 CrossNet+Attn+MLP
DHEN 代表了 CTR 模型的集大成方向: 与其争论哪种交互机制最好 (CrossNet? Attention? MLP?)，不如把它们全部组合起来，让模型自己学习最优的组合方式。这是「ensemble of interaction operators」的终极形态。
15
LHUC — Learning Hidden Unit Contributions

LHUC: 模型个性化而非特征交互 (Swietojanski & Renals, 2014)

重要区分: LHUC 不是特征交互模型，而是模型个性化/适配技术。它位于演进的另一条轴上。

h' = 2 * sigma(r_u) . h

- h: DNN 隐层激活 (共享模型)
- r_u: per-user 可学习参数向量
- sigma: sigmoid 函数
- 2*sigma(r): 值域 (0, 2)，可放大或缩小
- .: Hadamard product (逐元素乘)

核心机制:

- 为每个用户维护一组额外参数 r_u (维度 = 隐层宽度)

- 通过 2*sigma(r_u) 生成 per-user 的缩放因子 (值域 0 到 2)

- 逐元素缩放共享模型的隐层激活: 放大对该用户重要的特征通道，抑制不相关的

起源: 来自语音识别的 speaker adaptation (说话人适配)，被借鉴到推荐系统实现 user adaptation。

模型个性化 Per-user 缩放 语音识别起源 参数高效 Hadamard Scaling 非特征交互
LHUC 的独特定位: 它不改变特征交互的方式，而是在共享模型的基础上，用极少的 per-user 参数实现个性化适配。可以叠加在任何 CTR 模型之上 (DeepFM+LHUC, DCN+LHUC 等)。这代表了 CTR 演进的第二条主轴: 模型个性化。
*
两条演进主轴

CTR 模型演进的双轴框架

CTR 预估模型的演进可以沿两条正交的主轴理解:

主轴 1 -- 特征交互建模: 从 LR (无交互) -> POLY2 (暴力枚举) -> FM (分解交互) -> Wide&Deep/DeepFM (显式+隐式) -> DCN/xDeepFM (显式高阶) -> DCN-V2 (full-rank 交叉) -> DHEN (异构集成)。核心问题: 如何更好地建模特征之间的组合效应。

主轴 2 -- 模型个性化: 从「所有用户共享同一模型」到「per-user 参数化适配」。LHUC 代表这一方向: 在共享模型的基础上，用极少的 per-user 参数让模型行为因人而异。这条轴与特征交互正交 -- LHUC 可以叠加在任何特征交互模型之上。

核心演进逻辑总结

第一阶段: 线性到分解 (LR -> POLY2 -> FM -> FFM)

核心问题: 如何在稀疏数据上高效建模特征交互？答案是矩阵分解 (FM) 和 field-aware 精细化 (FFM)。这一阶段只解决了二阶交互。

第二阶段: 浅层+深层 (Wide&Deep -> DeepFM)

核心问题: 如何超越二阶？答案是引入 DNN 隐式学习高阶交互。DeepFM 用共享 Embedding 和 FM 自动交叉消除了手工特征工程。

第三阶段: 显式高阶 (DCN -> xDeepFM -> DCN-V2 -> MMCN)

核心问题: DNN 的隐式交互不可控。答案是设计专门的显式高阶交互机制 (Cross Layer, CIN)，在保持可控性的同时提升表达能力。

第四阶段: 工业集成 (DLRM -> DHEN)

核心问题: 单一交互机制有局限。答案是将多种异构算子组合在一起，形成更强大的集成模型。

正交轴: 个性化 (LHUC)

与特征交互演进正交的另一条线: 如何让模型行为因用户而异？LHUC 用 per-user 缩放因子实现轻量级个性化，可叠加在任何模型之上。
