前置术语表

LASSO 是什么缩写?

LASSO = Least Absolute Shrinkage and Selection Operator

中文：最小绝对值收缩与选择算子

名字本身概括了方法的两个核心功能：

Shrinkage 收缩 — 把系数往零压 Selection 选择 — 让部分系数=0

Tibshirani 取这个名字有一语双关的巧思—— lasso 在英语中是「套索」(牛仔套牛的绳子) 的意思，形象地表达了用 L1 约束把不重要变量「套住」清零的效果。

完整论文标题: Regression Shrinkage and Selection via the Lasso — 通过 LASSO 实现回归收缩与选择。

OLS = Ordinary Least Squares

OLS（普通最小二乘法）是最基础的线性回归方法。

目标很简单：找到一组系数 β，使预测值与真实值的残差平方和 (RSS) 最小：

min Σ(yᵢ - xᵢᵀβ)² = min ‖y - Xβ‖²

OLS 有直接的闭式解：

β̂ = (XᵀX)⁻¹Xᵀy

OLS 的问题：

- 无正则化：没有任何约束，当特征多、样本少时严重过拟合

- 无变量选择：给每个变量一个非零系数，即使该变量毫无用处

- 共线性敏感：当特征高度相关时，XᵀX 接近奇异，系数极不稳定

LASSO 的本质就是在 OLS 的基础上加了一个 L1 约束 Σ|βⱼ| ≤ t，以此获得正则化（防过拟合）和变量选择（稀疏性）的双重好处。

Lp 空间 = Lebesgue Space

L 来自法国数学家 Henri Lebesgue（亨利·勒贝格），p 是一个控制「怎么度量大小」的参数。

Lp 范数的通用定义：

‖β‖ₚ = ( |β₁|ᵖ + |β₂|ᵖ + ... + |βₙ|ᵖ )^(1/p)

不同的 p 值给出不同的度量方式和几何形状：

L0: 非零元素个数 L1: 绝对值之和 (曼哈顿距离) L2: 平方和开根 (欧氏距离) L∞: 最大绝对值 (切比雪夫距离)

左图展示了不同 p 值下「单位球」（满足 ‖β‖ₚ=1 的点集）的形状。p=1 的菱形有尖角，这正是 LASSO 产生稀疏的几何原因。

LASSO 选 L1 而非 L2 的本质：选了一个有尖角的约束形状。尖角位于坐标轴上（某些分量=0），等高线碰到尖角 → 解是稀疏的。

L1 约束到底是什么?

L1 约束是对参数向量的 L1 范数（各分量绝对值之和）施加上界限制：

Σ|βⱼ| = |β₁| + |β₂| + ... + |βₚ| ≤ t

预算类比：把 L1 约束想象成一个固定预算 t，你总共只有 t 元钱分配给所有系数。

由于花的是绝对值，模型会倾向于：

- 集中预算给少数重要变量（给它们较大的系数）

- 不重要变量直接分配 0（省下预算给更重要的）

这就是稀疏性的来源！

L1 vs L2 约束的关键区别

L1: Σ|βⱼ| ≤ t → 菱形，有尖角 → 稀疏! L2: Σβⱼ² ≤ t → 圆形，光滑 → 不稀疏
L2 约束像是「所有人工资打八折」(等比缩放)；L1 约束像是「每人先扣 λ 元固定税，不够扣的直接清零」(软阈值)。小系数被清零，大系数保留——这就是稀疏。

背景与动机

为什么需要 LASSO?

在 1996 年之前，统计建模面临两大核心挑战：

过拟合 — 当特征数量接近或超过样本数量时，普通最小二乘 (OLS) 会严重过拟合，泛化性能极差。

不可解释 — OLS 和岭回归都会给每个变量一个非零系数，无法告诉我们哪些变量真正重要。在基因组学、经济学等领域，变量选择和模型解释性至关重要。

已有方法各有缺陷：最优子集选择 (Best Subset Selection) 计算复杂度为 O(2ᵖ) 无法扩展；岭回归能收缩系数但不能让系数为零；逐步回归是贪心算法，不稳定。

Tibshirani 的洞察：能否找到一种方法，同时实现系数收缩（正则化）和变量选择（稀疏性），且计算高效？
2
核心思想

一个约束改变一切

LASSO (Least Absolute Shrinkage and Selection Operator) 的核心思想惊人地简洁：

minimize RSS(β) = Σ(yᵢ - xᵢᵀβ)²
subject to ‖β‖₁ = Σ|βⱼ| ≤ t

与岭回归 (Ridge) 唯一的区别是：将 L2 约束 Σβⱼ² ≤ t 替换为 L1 约束 Σ|βⱼ| ≤ t。

这个看似微小的改变产生了根本性不同的行为：

收缩 (Shrinkage) 变量选择 (Selection) 稀疏解 (Sparsity)

λ (或 t) 是唯一的超参数，控制稀疏程度。λ=0 退化为 OLS；λ→∞ 所有系数为零。通过交叉验证选择最优 λ。

名称含义: Least Absolute Shrinkage and Selection Operator — 最小绝对值收缩与选择算子。名字本身就概括了方法的两个核心功能。
3
几何直觉 — 为什么 L1 产生稀疏?

几何解释是 LASSO 最优美的部分

将 LASSO 视为约束优化问题，我们要在约束区域内找到使 RSS 最小的点。RSS 的等高线是以 OLS 估计 β̂ 为中心的同心椭圆。

L1 约束区域是一个菱形（高维中是超八面体），其「尖角」恰好位于坐标轴上。当 RSS 的等高线从 β̂ 向外扩展时，最先碰到菱形的地方大概率是某个「角」—— 而角上某些坐标值为零。

L2 约束区域是一个圆（高维中是超球），光滑无角。等高线与圆相切时，切点几乎不可能落在坐标轴上，所以系数不会精确为零。

高维效应: 在 p 维空间中，L1 超八面体有 2p 个顶角。维度越高，顶角越多，等高线碰到顶角的概率越大 → LASSO 在高维场景下特别适合做特征选择。
4
数学推导

软阈值算子 (Soft Thresholding)

当设计矩阵 X 正交 (XᵀX = I) 时，LASSO 有优雅的闭式解：

β̃ⱼ = sign(β̂ⱼ) · max(|β̂ⱼ| - λ, 0)

这就是软阈值算子 (Soft Thresholding Operator)：

- 如果 OLS 系数 |β̂ⱼ| ≤ λ，则 β̃ⱼ = 0（进入死区，被"杀死"）

- 如果 |β̂ⱼ| > λ，则系数被向零平移 λ 个单位

对比三种方法：

OLS: β̃ = β̂（无收缩） Ridge: β̃ = β̂/(1+λ)（等比缩放） LASSO: 软阈值（截断+平移）
Ridge 对所有系数做等比例缩放，大小系数同等对待。LASSO 则更"民主"——给每个系数一个固定的减免额度 λ，小系数直接归零，大系数保留。
5
求解算法

从二次规划到坐标下降

LASSO 的目标函数在 βⱼ=0 处不可导（L1 范数的"拐角"），不能直接用梯度下降。求解算法经历了重要演进：

1996 原论文 — Tibshirani 将 L1 约束转化为线性约束（令 βⱼ=βⱼ⁺-βⱼ⁻），用标准二次规划 (QP) 求解。可行但扩展性有限。

2004 LARS — Efron 等人提出 Least Angle Regression，可以用近似 OLS 的计算量求出整条正则化路径（所有 λ 对应的解），是理论上的突破。

2007 坐标下降 — Friedman、Hastie、Tibshirani 发现对 LASSO 逐坐标优化异常高效。固定其他坐标，每个 βⱼ 的子问题有闭式解（软阈值），反复循环即收敛。实现为 glmnet 包，成为事实标准。

坐标下降的核心迭代:
β̃ⱼ ← S(Σᵢ xᵢⱼ(yᵢ - ŷᵢ⁽⁻ʲ⁾), λ)
其中 S(z,λ) = sign(z)·max(|z|-λ, 0)
glmnet (2010) 成为 LASSO 最流行的实现，能在秒级处理百万级稀疏特征。坐标下降之所以高效，是因为 L1 惩罚是可分离的——每个坐标的子问题独立。
6
关键性质与理论保证

正则化路径与变量进入顺序

随着 λ 从大到小变化，LASSO 系数的变化轨迹称为正则化路径 (Regularization Path)：

- λ 很大时：所有系数为零（空模型）

- λ 逐渐减小：变量按重要性逐个进入模型，最重要的变量最先从零变为非零

- λ=0 时：退化为 OLS

这条路径本身就是一种变量重要性排序。

关键理论性质

稀疏一致性 — 在一定条件下（不可表示条件 / Irrepresentable Condition），LASSO 能以高概率正确识别真正的非零变量集合。

预测一致性 — 在更宽松的条件下，LASSO 的预测误差以最优速率收敛到零。

正则化路径的"分段线性"性质（LASSO 路径是 λ 的分段线性函数）使得 LARS 算法可以用 OLS 的计算量求出完整路径。这在交叉验证选择 λ 时极为高效。

LASSO vs 其他方法

方法全面对比

方法惩罚项变量选择多重共线性解的形式适用场景
LASSO (L1) λΣ|βⱼ| 是 (稀疏解) 不稳定 (随机选一个) 无闭式 (需迭代) 高维、需要特征选择
Ridge (L2) λΣβⱼ² 否 (系数≠0) 稳定 (均匀收缩) 闭式: (XᵀX+λI)⁻¹Xᵀy 多重共线性、所有变量相关
Elastic Net λ₁Σ|βⱼ|+λ₂Σβⱼ² 是 稳定 (分组效应) 无闭式 p≫n、相关特征组
Best Subset L0: |{j: βⱼ≠0}|≤k 是 (最优) — NP-hard (组合搜索) 小规模、理论基准
Adaptive LASSO Σwⱼ|βⱼ| 是 (Oracle 性质) 较稳定 无闭式 需要渐近 Oracle 性质

LASSO 的局限: (1) 当 p > n 时，最多选 n 个变量； (2) 在高度相关的变量组中，倾向随机选一个而非全选 → Elastic Net 解决此问题（"分组效应"）； (3) 对大系数有偏估计 → Adaptive LASSO / SCAD 解决此问题。

后续发展与变体

LASSO 引发的研究浪潮

1996 — LASSO
Tibshirani 提出 L1 正则化，奠定稀疏建模基础。
2001 — SCAD
Fan & Li 提出非凸惩罚 SCAD，实现 Oracle 性质（无偏估计 + 变量选择一致性）。
2004 — LARS
Efron et al. 提出 Least Angle Regression，高效计算完整正则化路径。
2005 — Elastic Net
Zou & Hastie 混合 L1+L2，解决 LASSO 在相关特征上的不稳定问题。
2006 — Adaptive LASSO
Zou 提出加权 L1 惩罚，给不同变量不同惩罚强度，获得 Oracle 性质。
2006 — Group LASSO
Yuan & Lin 提出组稀疏，一次选入/排除整组变量（如类别特征的所有 dummy 编码）。
2008 — Compressed Sensing
Candès, Tao 等人的 L1 最小化理论——用远少于 Nyquist 的测量恢复稀疏信号，获 Bôcher 奖。
2010 — glmnet
Friedman et al. 发布 glmnet 包，坐标下降实现使 LASSO 在工业界大规模应用成为可能。
2014 — Sparse Group LASSO
组间稀疏 + 组内稀疏的双层选择，在生物信息学和推荐系统中广泛应用。
2016+ — Deep Learning 中的稀疏
L1 正则化思想渗透到网络剪枝 (pruning)、稀疏注意力、MoE 等深度学习领域。

对推荐系统的深远影响

LASSO 思想在推荐系统中的 5 大应用

1. Embedding 稀疏化 — 在推荐系统中，Embedding 表占据 90%+ 的参数量。L1 正则化可以学习稀疏 Embedding，大幅减少存储和计算开销（如 DeepLight, AMTL）。

2. 自动特征选择 — CTR 模型中可能有数千个特征，L1 惩罚自动将不重要特征的权重压至零，替代人工特征筛选。

3. FM 族模型基础 — Factorization Machines 本质上是在稀疏特征空间中建模交互。LASSO 的稀疏特征处理思想直接影响了 FM 的设计哲学。

4. 推荐模型压缩 — 工业推荐系统需要在线推理，L1 正则化驱动的结构化剪枝（权重归零→删除连接/神经元）是模型压缩的核心技术。

5. MoE 稀疏激活 — MoE 中的 Top-k 门控本质上是一种稀疏选择机制，与 LASSO 的 L1 约束在精神上一脉相承——都是用稀疏性换效率。

从高维稀疏特征到稀疏 Embedding，从 L1 特征选择到 MoE 稀疏激活——LASSO 的核心思想「用稀疏性 (sparsity) 在模型容量和计算效率之间取得最佳平衡」贯穿了推荐系统技术的整个演进历程。
