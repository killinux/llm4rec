1
核心问题：稀疏特征如何交互?

为什么特征交互如此重要?

CTR (Click-Through Rate) 预估的核心挑战是从高维稀疏特征中学习有效的特征交互模式。

单独看「性别=女」和「广告类目=美妆」可能各自有一定的点击倾向，但它们的组合效应远大于各自贡献之和。

特征交互分为不同阶数：

一阶 — 每个特征独立贡献，线性模型 (LR) 即可

二阶 — 两个特征配对交互，FM 通过分解权重矩阵高效建模

高阶 — 三个及以上特征的组合模式，需要 DNN 或 CIN

FM → DeepFM → xDeepFM 的演进主线就是：如何更好、更高效、更可控地建模越来越高阶的特征交互。
2
FM — Factorization Machines (2010)

FM: 用分解的隐向量建模二阶交互

核心公式:

ŷ = w₀ + Σᵢ wᵢxᵢ + Σᵢ Σⱼ₌ᵢ₊₁ ⟨vᵢ, vⱼ⟩ · xᵢxⱼ

三个组成部分：

w₀ — 全局偏置

Σwᵢxᵢ — 一阶线性项（等同于 LR）

Σ⟨vᵢ,vⱼ⟩xᵢxⱼ — 二阶交互项（FM 的核心创新）

关键洞察: 不直接学习 n×n 的交互权重矩阵 W（参数太多、稀疏数据学不动），而是将其分解为：

wᵢⱼ ≈ ⟨vᵢ, vⱼ⟩ = Σₖ vᵢₖ · vⱼₖ

每个特征用一个 k 维隐向量 vᵢ 表示，交互权重 = 隐向量的内积。

FM 的天才之处: 通过数学变换，复杂度从 O(kn²) 降到 O(kn)。而且即使特征 i 和 j 从未在训练数据中共同出现，只要它们各自与其他特征有过交互，就能通过隐向量泛化出 wᵢⱼ。
3
FM 的局限

FM 的两大局限

局限一：只能建模二阶交互

FM 的交互项 Σ⟨vᵢ,vⱼ⟩xᵢxⱼ 只涉及两个特征的配对。现实中大量有价值的模式来自三个及以上特征的组合（如 性别×年龄×广告类目×时间段）。

局限二：交互是线性组合

即使二阶交互，也只是简单的内积（线性操作）。无法捕获非线性的复杂交互模式。

理论上可以扩展到高阶 FM (d-way FM):

ŷ = w₀ + Σwᵢxᵢ + Σ⟨vᵢ,vⱼ⟩xᵢxⱼ + Σ⟨vᵢ,vⱼ,vₖ⟩xᵢxⱼxₖ + ...

但复杂度呈指数增长，实际中很少使用超过二阶。

这就是 DeepFM 的动机: 用 DNN 来自动学习高阶非线性交互，同时保留 FM 对二阶交互的高效建模。
4
DeepFM — FM + DNN 共享 Embedding (2017)

DeepFM: 低阶 + 高阶的完美互补

DeepFM 的设计哲学：FM 擅长低阶显式交互，DNN 擅长高阶隐式交互，让它们各司其职。

ŷ = σ(y_FM + y_DNN)
y_FM = w₀ + Σwᵢxᵢ + Σ⟨eᵢ,eⱼ⟩
y_DNN = DNN(concat(e₁, e₂, ..., eₘ))

架构的三个关键设计：

1. 共享 Embedding — FM 和 DNN 使用同一组 Embedding 向量，互相增强学习

2. FM 组件 — 保留 FM 的一阶和二阶交互建模能力

3. DNN 组件 — 将所有 field 的 Embedding 拼接后送入多层全连接网络，隐式学习任意阶交互

共享 Embedding 是核心创新。FM 侧的梯度和 DNN 侧的梯度共同优化同一组 Embedding，使得低阶交互信号和高阶交互信号互相补充，比分别训练效果好。
5
DeepFM vs Wide&Deep

DeepFM 相比 Wide&Deep 的三大改进

改进一：消除特征工程

Wide&Deep 的 Wide 侧需要人工设计交叉特征 φ(x)（如 gender×ad_category），这依赖领域知识且不可扩展。DeepFM 用 FM 组件自动学习所有二阶交互，无需任何手工特征工程。

改进二：共享 Embedding

Wide&Deep 的 Wide 侧和 Deep 侧使用不同的输入表示。DeepFM 让 FM 和 DNN 共享同一组 Embedding 向量，两侧的梯度共同优化，信息互相流通。

改进三：端到端统一训练

Wide&Deep 原论文中 Wide 侧用 FTRL 优化、Deep 侧用 AdaGrad，训练流程不统一。DeepFM 完全端到端，一个优化器搞定。

本质区别：Wide&Deep 的 Wide 侧是记忆（死记硬背高频共现模式），DeepFM 的 FM 侧是建模（通过隐向量泛化到未见过的特征组合）。后者更强大。
6
DeepFM 的局限

DNN 的高阶交互是不可控的

DeepFM 虽然通过 DNN 获得了高阶交互能力，但存在两个根本性问题：

问题一：隐式黑盒

DNN 到底学到了哪些高阶交互？是三阶还是五阶？涉及哪些特征？完全不可知。我们无法控制交互的阶数，也无法解释 DNN 学到的交互模式。

问题二：bit-wise 交互

DNN 将所有 field 的 Embedding 拼接后送入全连接层，各维度会被打散混合。这种 bit-wise 交互破坏了每个 field embedding 的向量结构——「用户年龄」的第 3 维和「广告类目」的第 7 维直接相乘，失去了 field 级别的语义。

这就是 xDeepFM 的动机: 能否设计一种机制，在保留 field 向量结构的前提下，显式地建模任意阶交互，且交互阶数可控？
7
xDeepFM — CIN + DNN (2018)

xDeepFM: 显式 + 隐式的终极组合

x = eXtreme，xDeepFM 的目标是同时实现显式和隐式的任意阶特征交互。

ŷ = σ(y_Linear + y_CIN + y_DNN)

由三个组件构成：

Linear — 一阶线性项 Σwᵢxᵢ

CIN (核心创新) — Compressed Interaction Network，在 vector 级别显式建模有界阶交互。每多一层 CIN，交互阶数 +1，阶数完全可控。

DNN — 与 DeepFM 相同，隐式学习高阶 bit-wise 交互作为补充。

xDeepFM = CIN + DNN + Linear，其中 CIN 是全新组件，用 vector-wise 的显式交互替代了 DeepFM 中 FM 的角色，且可以建模任意阶交互（不限于二阶）。
8
CIN 详解 — 压缩交互网络

CIN 的工作原理

CIN 的核心操作是逐层外积 + 压缩：

Step 1: 将当前层 Xᵏ 的每个向量与 X⁰ 的每个向量做逐元素相乘（Hadamard 积，不是 DNN 里的拼接），生成中间张量。

Step 2: 用可学习的参数矩阵 W 将中间张量压缩为 Hₖ₊₁ 个新向量，作为下一层 Xᵏ⁺¹。

Xᵏ⁺¹ₕ = Σᵢ Σⱼ Wᵏₕᵢⱼ (Xᵏᵢ ∘ X⁰ⱼ)

关键设计: 每一层都与 X⁰（原始 field embeddings）做外积，而不是与前一层。这保证了：

- 第 1 层 = X⁰ × X⁰ → 二阶交互

- 第 2 层 = X¹ × X⁰ → 三阶交互

- 第 T 层 = X^(T-1) × X⁰ → (T+1) 阶交互

最后，每一层的输出做 sum pooling 后拼接，送入输出层。

"Compressed" 的含义: 外积会生成 Hₖ × m 个中间向量，通过 W 矩阵压缩为 Hₖ₊₁ 个，避免指数级膨胀。这就是"压缩交互网络"名字的由来。
9
Bit-wise vs Vector-wise 交互

xDeepFM 提出的关键概念区分

这是 xDeepFM 论文最重要的理论贡献之一：明确区分了两种特征交互方式。

Bit-wise 交互 (DNN/FM)

将所有 field embedding 拼接成一个长向量后送入全连接层，不同 field 的不同维度会被打散混合。例如「年龄 embedding 的第 3 维」×「广告 embedding 的第 7 维」—— 这种交互缺乏明确的语义含义。

Vector-wise 交互 (CIN)

将每个 field 的 embedding 作为一个整体向量，做 Hadamard 积（逐元素乘）。例如「年龄向量」∘「广告向量」—— 交互的语义单位是 field 级别，含义明确且可解释。

为什么 vector-wise 更好?
1. 保留了 field 的语义结构 → 更可解释
2. 交互的粒度更合理 → 噪声更少
3. CIN 每层的交互阶数明确 → 可控性强
xDeepFM 同时使用两者: CIN 做 vector-wise 显式交互，DNN 做 bit-wise 隐式交互，互为补充。

FM 的角色

理论基石。证明了稀疏特征可以通过隐向量内积高效交互。所有后续工作的起点。

DeepFM 的角色

工业标配。共享 Embedding + 端到端训练使其成为效果和效率的最佳平衡点。

xDeepFM 的角色

理论深化。提出 bit-wise vs vector-wise 的概念框架，影响了后续所有交互建模研究。

11
如何选择?

实践建议

选 FM: 算力受限、需要低延迟的场景（如端侧推理）。特征交互以二阶为主的简单任务。FM 参数少、训练快、可解释。

选 DeepFM: 工业推荐的标准选择。效果和效率的最佳平衡点。共享 Embedding + 端到端训练，工程实现简洁。绝大多数场景的首选 baseline。

选 xDeepFM: 需要可解释的高阶交互分析，或需要精确控制交互阶数的研究场景。注意 CIN 的计算开销较大。

补充说明: 在 2018 年之后，还有更多后续模型值得关注：

DCN-V2 (2020) — 改进的交叉网络 AutoInt (2019) — 自注意力交互 FiBiNET (2019) — 双线性交互 DLRM (2019) — Meta 的工业方案
演进主线总结:
FM (二阶显式) → DeepFM (二阶显式 + 任意阶隐式) → xDeepFM (任意阶显式 + 任意阶隐式)
每一步都在解决前一步的核心局限，同时保留前一步的优势。
